# How to run ULTIMATE STREET RACING

1. Install Node.js 20 or newer: https://nodejs.org
2. Unzip this folder and open a terminal inside it.
3. Install the parts the game needs:
       npm install
4. Start the game:
       npm run dev
5. Open the address it prints (usually http://localhost:8080) in Chrome, Edge or Firefox.

Note: the game is still being built. Menus, the race screen and the on-screen
mobile buttons are not finished yet, so the home page is still a blank starter page.
